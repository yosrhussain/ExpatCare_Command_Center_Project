# ExpatCare Command Center

AI-powered healthcare claims automation system for Dubai’s expat ecosystem. The project uses multi-agent AI workflows, OCR, RAG, fraud detection, policy interpretation, and intelligent decisioning to automate insurance claim processing.

## Key Features
- Multi-agent AI workflow
- OCR-based document extraction
- RAG-based policy interpretation
- Fraud risk detection
- Claims decision routing
- Demo workflow video

## Technologies
Python, Jupyter Notebook, OCR, RAG, Opus AI Agents, HTML, JSON
